# UI Specs

- **Colores**: Mantener clases de Tailwind / CSS Vanilla usando las variables CSS `--bg-color`, `--text-color` existentes.
- **Layout**: 
  - Sidebar izquierdo (o Navbar superior en móvil).
  - Área principal a la derecha.
- **UsersView**:
  - Tabla simple con columnas: ID, Nombre, Rol, Acciones.
  - Formulario arriba o abajo de la tabla: Input `Nombre`, Select `Rol` (Administrador, Lector), Botón `Crear`.
